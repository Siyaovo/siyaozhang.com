# siyaozhang.com

Personal site of Siyao Zhang. Live at [siyaozhang.com](https://siyaozhang.com), served by GitHub Pages from `main`.

## Edit

All three languages come from one file. Edit the `PAGES` dict in `_build/build.py`, then run:

```bash
python3 _build/build.py
```

Never edit `index.html`, `zh.html` or `fr.html` by hand.

## Versions

Every published version has a tag. `before-2026-11` is the site as it was before the November 2026 redesign. To roll back:

```bash
git checkout <tag> -- .
```
