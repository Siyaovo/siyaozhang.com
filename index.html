Agent Evaluation · Open Source 2026

Mini Agent Harness — a small harness and the regression set that checks it

Public GitHub repo · Python standard library only · 14 regression cases

A small agent harness: a loop with a step limit, two tools, a trace of every step, and a rule that the agent can only propose a file change until a person confirms it. The regression set covers normal runs, tool errors, safety, model errors, stopping and confirmation.

Checking the checks: I broke the path guard and the overwrite check on purpose to see whether the cases would catch it. One case still passed, because the file it tried to read did not exist. I fixed the case so it plants a real file.

Technical Demo · Open Source 2026

Function Calling Demo — a minimal Anthropic tool-use loop

Public GitHub repo · ~350 lines of Python · 13 pytest tests (security boundary included)

A minimal tool-use agent written without any framework — direct Anthropic API. Ships 5 typed tools (each with a JSON Schema), a dispatcher, a path-traversal guard enforced at the handler level, and a MAX_TOOL_ITERATIONS cap with a comment explaining when it should fire. Built to understand the primitive, not the framework.

Why this exists: every agent framework (LangChain, AutoGen, Claude Agent SDK) wraps the same loop. Seeing it plain makes the design trade-offs visible — why typed tools beat a god-tool, why the boundary check lives in code not prompt, and why hitting the iteration cap often points to a problem in tool design or task splitting.

Research · NLP 2025

Robotics Exposure Index for European Labour Markets

Big Data for Development — Group research, Panthéon-Sorbonne

Download poster

Exposure index for European occupations to robotics adoption, via LSA on patent + job-description corpora. Middle-wage routine-task jobs face the highest automation risk (consistent with labour market polarisation theory).

Result: across 34 European countries, one standard deviation more robotics exposure is associated with 7.2% lower mean hourly wages (β = −0.072, p < 0.001). This is a correlation, not a causal estimate.
